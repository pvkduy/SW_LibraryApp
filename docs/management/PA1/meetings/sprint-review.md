### **Sprint results** 

- Sprint goal: Complete the PA1 package (group and topic registration, project proposal, existing app survey, team contract) and set up the project tools (GitHub, Google Drive, Jira, AI coding accounts).  
- Goal met: Yes  
- Planned vs. completed tasks: 9/9  (from the final Jira board)  
- Deliverables: Project proposal, app survey and comparison, team contract, Jira board, GitHub repository, git log, meeting minutes, AI coding account evidence

### **What went well**

- Tool setup was finished early: the Jira workspace, the GitHub repository with README and folder structure, and the shared Firebase account.  
- Group and topic registration was completed at the start of the sprint.  
- The app survey was written and revised after leader review on schedule, with no open issues at Scrum Meeting \#2.  
- The team contract was drafted, reviewed and finalized with feedback from every member.  
- All five members attended all three meetings, and the team reviewed each other’s work (proposal, survey, contract) before finalizing it.

### **What went wrong**

- The project proposal was only fully drafted late in the sprint, because the feature list was not detailed enough early on (exact flows and total number of functions). It was lacking robustness for edge cases and many user stories were unclear so completing the document required multiple rounds of refinements and revision.  
- Unfamiliarity with Scrum slowed the initial setup because most members had not used Scrum or Jira before, so the framework had to be worked out from scratch.  
- Few suitable apps to survey, especially staff or administrator-side apps since most library-related apps are built for reading and book management, not purely library administrative services.

### **Lessons learned**

- Framework and tool setup takes real time, so it should be planned as sprint tasks.  
- A detailed, agreed scope early saves effort during writing and review.  
- Raising blockers in Scrum meetings gets them resolved faster than leaving them in chat.  
- Cross-review by teammates caught problems before submission.
